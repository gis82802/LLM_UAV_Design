# AI 無人機設計協作平台

本專案是一個先進的 AI
驅動協作平台，旨在協助無人機（UAV）的設計與元件選擇。它利用多個大型語言模型（LLM），提供全面且互動的設計體驗。平台採用兩階段流程：首先進行初步的任務分析，然後是詳細的元件查詢，所有功能都可透過一個友善的
Gradio Web 介面進行操作。

## ✨ 主要功能

-   **支援多種 LLM：** 平台架構可支援並在多種 LLM 組態之間切換，包含來自
    Ollama 的模型（例如 Llama3.3、gpt-oss）以及代理模型（例如
    GPT-5-mini）。這允許使用者進行比較分析，並靈活選擇最適合特定任務的模型。
-   **兩階段設計流程：**
    1.  **任務分析：**
        使用者可以用自然語言描述他們的任務需求。系統會對任務提供高層次的分析，拆解出推進與能源、感測器與資料鏈、結構與機體等模組的關鍵設計考量。
    2.  **元件查詢：**
        在任務分析之後，使用者可以針對特定元件提出問題。系統會使用「檢索增強生成」（RAG）流程，基於無人機零件的知識庫，提供詳細的元件建議。
-   **先進的 RAG 流程：** RAG 流程是此平台的核心。它使用
    `ParentDocumentRetriever` 從 Chroma
    向量儲存庫中檢索相關文件。檢索到的文件接著會透過一個 cross-encoder
    模型進行重新排序，以提供最相關的上下文給 LLM，用於生成回應。
-   **Gradio 使用者介面：** 平台包含一個以 Gradio 打造的直觀且互動的 Web
    介面。此介面讓使用者可以從可用的 LLM
    組態中選擇、輸入他們的任務與查詢，並以清晰、有組織的方式查看結果。它還會即時更新
    AI 回應生成過程中不同階段的狀態。
-   **模組化與可擴展性：** 本專案在設計時考慮了模組化，使其易於新增 LLM
    組態、更新知識庫或修改提示詞模板。

## 📂 專案結構

    .
    ├── api_server_multi_llm.py  # FastAPI 伺服器，處理 API 請求並調度不同模型。
    ├── config.py                # 包含所有模型、路徑和其他設定的組態檔。
    ├── gradio_ui_chatbot.py     # 用於與平台互動的 Gradio 使用者介面。
    ├── models.py                # Pydantic 模型，用於無人機元件知識庫的資料驗證與結構化。
    ├── prompts.py               # 用於翻譯、分析和 RAG 的所有提示詞模板。
    └── rag_handler.py           # 處理檢索增強生成（RAG）流程的邏輯。

## 🚀 運作方式

1.  **使用者輸入：** 使用者透過 Gradio
    介面與系統互動，可以提供初始的任務描述，或提出特定的元件相關問題。
2.  **API 請求：** Gradio UI 會發送一個請求到 FastAPI 伺服器
    (`api_server_multi_llm.py`)。
3.  **請求處理：**
    伺服器接收請求，並根據當前階段（任務分析或元件查詢），啟動相應的流程。
4.  **翻譯與分析：**
    使用者的中文查詢會先由指定的翻譯模型翻譯成英文。對於初始的任務分析，英文查詢會被用來生成高層次的設計分析。對於元件查詢，查詢會被分析以提取關鍵字和元件類型。
5.  **RAG 流程（用於元件查詢）：**
    -   **檢索：** `rag_handler.py` 使用提取的關鍵字和元件類型，從
        Chroma 向量儲存庫中檢索相關文件。
    -   **重新排序：** 檢索到的文件會被重新排序，以提升提供給 LLM
        的上下文品質。
    -   **生成：**
        重新排序後的上下文，連同使用者的查詢和其他情境資訊，會被傳遞給
        LLM，以生成詳細且附帶理由的元件建議。
6.  **回應翻譯：** 生成的英文回應會被翻譯回中文。
7.  **串流至 UI：** 最終的回應會以串流方式傳回 Gradio
    UI，並顯示給使用者。

## 🛠️ 開始使用

### 環境需求

-   Python 3.8+
-   一個正在運行的 Ollama 伺服器，並已部署 `config.py` 中指定的模型。
-   一個正在運行的向量儲存庫（例如 Chroma），並已載入無人機元件資料。
-   為任何代理模型設定必要的環境變數。

### 安裝

1.  複製儲存庫： `bash     git clone <repository-url>`
2.  安裝所需的 Python 套件： `bash     pip install -r requirements.txt`
3.  設定您的 `.env` 檔案，包含任何代理模型所需的 API 金鑰。

### 執行應用程式

1.  啟動 FastAPI 伺服器： `bash     python api_server_multi_llm.py`
2.  在另一個終端機中，啟動 Gradio UI：
    `bash     python gradio_ui_chatbot.py`
3.  打開您的網頁瀏覽器，並前往 Gradio 提供的 URL（通常是
    `http://127.0.0.1:7860`）。

## 🔧 客製化

-   **新增模型：** 若要新增 LLM 組態，只需在 `config.py` 的
    `MODEL_CONFIGURATIONS`
    字典中新增一個條目即可。您需要指定模型名稱、類型（Ollama 或
    proxy）以及任何其他必要參數。
-   **更新知識庫：** RAG 流程的知識庫可以透過在 `data_1`
    目錄中新增或修改 JSON 檔案來更新。伺服器啟動時，`rag_handler.py`
    會自動處理這些檔案。
-   **修改提示詞：** 可以透過修改 `prompts.py` 中的提示詞模板，來客製化
    LLM 的行為。
